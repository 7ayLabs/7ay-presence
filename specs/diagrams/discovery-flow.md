## 2. Node Announcement Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ANNOUNCEMENT PHASE                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   ┌──────────┐                                                              │
│   │  Node A  │                                                              │
│   │ (Joined) │                                                              │
│   └────┬─────┘                                                              │
│        │                                                                    │
│        │  1. Create NODE_ANNOUNCE                                           │
│        │     ┌────────────────────────────────────────┐                     │
│        │     │ version: "0.6.0"                       │                     │
│        │     │ type: NODE_ANNOUNCE                    │                     │
│        │     │ sender: { address, publicKey }         │                     │
│        │     │ epochId: 42                            │                     │
│        │     │ timestamp: 1704067200                  │                     │
│        │     │ nonce: 1                               │                     │
│        │     │ signature: 0x...                       │                     │
│        │     │ payload: { role, capabilities, ttl }   │                     │
│        │     └────────────────────────────────────────┘                     │
│        │                                                                    │
│        ▼  2. Broadcast to Known Peers                                       │
│   ┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐              │
│   │ Peer 1  │     │ Peer 2  │     │ Peer 3  │     │ Peer N  │              │
│   └────┬────┘     └────┬────┘     └────┬────┘     └────┬────┘              │
│        │               │               │               │                    │
│        │  3. Each Peer Verifies Announcement                                │
│        ▼               ▼               ▼               ▼                    │
│   ┌─────────────────────────────────────────────────────────────────┐      │
│   │                     VERIFICATION STEPS                           │      │
│   │  a. Verify signature against sender.address                      │      │
│   │  b. Check epochId matches current epoch                          │      │
│   │  c. Query on-chain: presenceState(sender, epochId)               │      │
│   │  d. Verify role claim against ValidatorRegistry                  │      │
│   │  e. If valid → Add to peer list with TTL                         │      │
│   └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. Epoch Transition Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       EPOCH TRANSITION                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   EPOCH 42 (Active)                     EPOCH 43 (Scheduled → Active)       │
│   ─────────────────                     ─────────────────────────────       │
│                                                                              │
│   ┌────────────────────┐               ┌────────────────────┐               │
│   │ Peer List Epoch 42 │               │ Peer List Epoch 43 │               │
│   │ ┌────────────────┐ │               │ ┌────────────────┐ │               │
│   │ │ Node A         │ │               │ │ (empty)        │ │               │
│   │ │ Node B         │ │               │ └────────────────┘ │               │
│   │ │ Node C         │ │               └────────────────────┘               │
│   │ └────────────────┘ │                         │                          │
│   └────────────────────┘                         │                          │
│            │                                     │                          │
│            │  Epoch 42 Closes                    │                          │
│            │  Epoch 43 Activates                 │                          │
│            ▼                                     ▼                          │
│   ┌────────────────────┐               ┌────────────────────┐               │
│   │ Epoch 42 (Closed)  │               │ Epoch 43 (Active)  │               │
│   │ ┌────────────────┐ │               │ ┌────────────────┐ │               │
│   │ │ No new peers   │ │               │ │ Node A         │ │ (re-joined)  │
│   │ │ Finalization   │ │               │ │ Node D         │ │ (new)        │
│   │ └────────────────┘ │               │ └────────────────┘ │               │
│   └────────────────────┘               └────────────────────┘               │
│                                                                              │
│   KEY POINTS:                                                                │
│   • Peer lists are epoch-scoped (INV21)                                     │
│   • Nodes must re-declare presence in new epoch                             │
│   • Old epoch peer lists preserved for finalization                         │
│   • Discovery queries filter by epoch                                        │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. Identity Verification Sequence

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     IDENTITY VERIFICATION (INV22)                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   Receiving Node                        On-Chain Registries                  │
│   ──────────────                        ────────────────────                 │
│        │                                      │                              │
│        │  Received NODE_ANNOUNCE              │                              │
│        │  from address 0xABC...               │                              │
│        │                                      │                              │
│        │  1. Verify Signature                 │                              │
│        │  ┌────────────────────────────┐     │                              │
│        │  │ hash = keccak256(          │     │                              │
│        │  │   type || sender || epoch  │     │                              │
│        │  │   || timestamp || nonce    │     │                              │
│        │  │   || payloadHash           │     │                              │
│        │  │ )                          │     │                              │
│        │  │ signer = ecrecover(        │     │                              │
│        │  │   hash, signature          │     │                              │
│        │  │ )                          │     │                              │
│        │  │ assert signer == sender    │     │                              │
│        │  └────────────────────────────┘     │                              │
│        │                                      │                              │
│        │  2. Check Presence                   │                              │
│        ├─────────────────────────────────────►│                              │
│        │  presenceRegistry.presenceState(     │                              │
│        │    0xABC, epochId                    │                              │
│        │  )                                   │                              │
│        │◄─────────────────────────────────────┤                              │
│        │  Returns: Declared | Validated |     │                              │
│        │           Finalized                  │                              │
│        │                                      │                              │
│        │  3. Verify Role (if Validator)       │                              │
│        ├─────────────────────────────────────►│                              │
│        │  validatorRegistry.isValidatorActive(│                              │
│        │    0xABC                             │                              │
│        │  )                                   │                              │
│        │◄─────────────────────────────────────┤                              │
│        │  Returns: true/false                 │                              │
│        │                                      │                              │
│        │  4. Add to Peer List                 │                              │
│        │  ┌────────────────────────────┐     │                              │
│        │  │ if all checks pass:        │     │                              │
│        │  │   peerList.add(node, ttl)  │     │                              │
│        │  └────────────────────────────┘     │                              │
│        │                                      │                              │
│        ▼                                      │                              │
│   ┌──────────────────┐                       │                              │
│   │ Verified Peer    │                       │                              │
│   └──────────────────┘                       │                              │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
