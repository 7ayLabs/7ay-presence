# Octopus Scaling Flow Diagrams

## 1. Division Flow

```
┌──────────────┐
│  Node (P)    │
│ throughput   │
│   > 45%      │
└──────┬───────┘
       │
       ▼
┌──────────────────────────────────────────┐
│         OCTOPUS_THRESHOLD (0x60)         │
│  { thresholdType: ACTIVATION }           │
└──────────────────────────────────────────┘
       │
       │ Validators acknowledge
       ▼
┌──────────────────────────────────────────┐
│           OCTOPUS_DIVIDE (0x61)          │
│  { subNodeCount: 2, divisionLevel: 1 }   │
└──────────────────────────────────────────┘
       │
       ├────────────────────┐
       ▼                    ▼
┌──────────────┐     ┌──────────────┐
│  Sub-Node 0  │     │  Sub-Node 1  │
│ range: 0-127 │     │ range: 128-255│
└──────┬───────┘     └──────┬───────┘
       │                    │
       ▼                    ▼
┌──────────────────────────────────────────┐
│         OCTOPUS_SUBNODE (0x62)           │
│  { index: 0/1, assignedRange: ... }      │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│        OCTOPUS_COORDINATE (0x63)         │
│  { coordinationType: HEARTBEAT }         │
└──────────────────────────────────────────┘
```

```
  │                          │

```

## 7. State Machine

```
                    ┌──────────┐
                    │  NORMAL  │
                    └────┬─────┘
                         │
                         │ throughput > 45%
                         ▼
                    ┌──────────┐
                    │ DIVIDING │
                    └────┬─────┘
                         │
                         │ sub-nodes registered
                         ▼
                    ┌──────────┐
        ┌──────────│ DIVIDED  │──────────┐
        │          └────┬─────┘          │
        │               │                │
        │ sub-node      │                │ throughput < 20%
        │ failure       │                │ (sustained 5 min)
        ▼               │                ▼
   ┌──────────┐         │          ┌──────────┐
   │ FAILOVER │─────────┤          │ MERGING  │
   └──────────┘         │          └────┬─────┘
        │               │               │
        │ recovered     │               │ states reconciled
        └───────────────┘               │
                                        ▼
                                   ┌──────────┐
                                   │  NORMAL  │
                                   └──────────┘
```
